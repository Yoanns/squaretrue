# Security policy

## Reporting a vulnerability

Please report security issues privately via GitHub:
[Report a vulnerability](https://github.com/Yoanns/squaretrue/security/advisories/new).
Do not open a public issue for vulnerabilities.

Squaretrue ships instructions, not executable code. Relevant reports include
skill text that could lead an agent to bypass its authorization boundary,
expose secrets, or act on untrusted repository content.

## Supported versions

Only the latest version is supported.
